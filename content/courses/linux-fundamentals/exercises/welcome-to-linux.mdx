Welcome to **Linux Fundamentals**! This course will teach you the essential skills needed to navigate and work with Linux systems - a critical foundation for cybersecurity professionals.

## What is Linux?

Linux is a powerful, open-source operating system that powers:

- 🖥️ Servers (over 90% of web servers run Linux)
- 📱 Android devices
- ☁️ Cloud infrastructure
- 🔒 Cybersecurity tools
- 🚀 Supercomputers

## Why Learn Linux for Cybersecurity?

As a cybersecurity professional, Linux is essential because:

1. **Penetration Testing Tools** - Kali Linux, Parrot OS, and most hacking tools run on Linux
2. **Server Security** - Most servers you'll secure or test run Linux
3. **Powerful Command Line** - Automation and scripting capabilities
4. **Transparency** - Open source means you can see exactly what's happening
5. **Industry Standard** - Required knowledge for security roles

## The Terminal

Unlike graphical interfaces you might be used to, Linux power users work primarily through the **terminal** (also called the shell or command line). The terminal allows you to:

- Execute commands quickly
- Automate repetitive tasks
- Work with remote servers
- Access powerful system tools

## Your Practice Environment

On the right side of this page, you'll find an **interactive terminal emulator**. This is a safe, sandboxed environment where you can practice Linux commands without affecting your computer.

Try typing your first command:

```bash
whoami
```

This command tells you the current user (in this case, "user").
