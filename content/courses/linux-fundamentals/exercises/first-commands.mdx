Welcome to your first hands-on Linux exercise! In this lesson, you'll learn some of the most basic and essential commands that every Linux user should know.

## Learning Objectives

By the end of this exercise, you will be able to:

- Display text using the `echo` command
- Check the current date and time
- View system information
- Clear the terminal screen

## The echo Command

The `echo` command displays text to the terminal. It's one of the simplest commands but very useful for displaying messages.

**Try this:**

```bash
echo "Hello, Linux!"
```

You can also use `echo` to display variables or combine multiple words:

```bash
echo Welcome to CyberCodex
```

## Checking the Date

The `date` command shows the current date and time:

```bash
date
```

## System Information

Want to know what system you're running? Use the `uname` command:

```bash
uname
```

For more detailed information, add the `-a` flag:

```bash
uname -a
```

## Clearing the Screen

When your terminal gets cluttered, use `clear` to start fresh:

```bash
clear
```

**Note:** This command will clear all the output from your screen!

## Tips

- Commands are case-sensitive in Linux (`Echo` won't work, only `echo`)
- You can combine commands on one line with `&&`: `date && whoami`
- Press Ctrl+L as a shortcut for `clear`
