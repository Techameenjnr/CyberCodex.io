The `cd` command (change directory) is your primary tool for navigating the Linux filesystem. Mastering `cd` is essential for efficient command-line work.

## Learning Objectives

- Change to different directories
- Use absolute and relative paths
- Navigate to home directory
- Move up directory levels
- Understand the directory structure

## Basic Usage

To change to a directory, use:

```bash
cd directory_name
```

For example:

```bash
cd documents
cd /home/user
cd /etc
```

## Going Home

Running `cd` with no arguments takes you to your home directory:

```bash
cd
```

You can also use the tilde (`~`) symbol:

```bash
cd ~
```

## Going Up One Level

Use `..` to go up one directory level:

```bash
cd ..
```

## Going Up Multiple Levels

You can chain `..` to go up multiple levels:

```bash
cd ../..
```

This moves up two directory levels.

## Absolute vs Relative Paths

**Absolute paths** start from the root directory (`/`):

```bash
cd /home/user/documents
cd /etc
```

**Relative paths** start from your current location:

```bash
cd documents           # Goes to documents in current directory
cd ./documents        # Same as above (. means current directory)
cd ../downloads       # Go up one level, then into downloads
```

## Special Directory Symbols

- `.` - Current directory
- `..` - Parent directory (one level up)
- `~` - Home directory
- `/` - Root directory (top of filesystem)

## Practice Challenges

1. Go to your home directory
2. Change to `/home/user/documents`
3. Go up one directory level
4. Go to `/tmp` directory
5. Return to your home directory

Try these commands to verify where you are:

```bash
pwd    # Prints your current directory
ls     # Lists contents of current directory
```

## Common Patterns

```bash
cd            # Go home
cd ~          # Go home (alternative)
cd -          # Go to previous directory
cd /          # Go to root directory
cd ..         # Go up one level
cd ../..      # Go up two levels
```

## Tips

- If a directory name has spaces, use quotes: `cd "My Documents"`
- Tab completion helps! Type `cd doc` and press Tab to auto-complete
- Use `pwd` to check where you are after using `cd`
- The `ls` command shows what directories you can `cd` into
