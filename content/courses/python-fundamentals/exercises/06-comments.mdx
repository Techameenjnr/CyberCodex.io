## Code Comments

Comments are notes in your code that Python ignores. They help you (and others) understand what your code does!

### Single-Line Comments

In Python, comments start with `#`:

```python
# This is a comment
print("Hello")  # This is also a comment
```

### Why Use Comments?

1. **Explain complex code** - Help others understand your logic
2. **Document your work** - Remember what you did later
3. **Temporarily disable code** - Test without deleting

```python
# Calculate the area of a rectangle
width = 10
height = 5
area = width * height

# print(area)  # Temporarily disabled
```

### Good vs Bad Comments

**Good Comments** - Explain WHY:
```python
# Convert temperature from Celsius to Fahrenheit
fahrenheit = celsius * 9/5 + 32
```

**Bad Comments** - State the obvious:
```python
# Add 5 and 3
result = 5 + 3  # This is obvious from the code
```

### Multi-line Comments

For longer explanations, use multiple `#` symbols:

```python
# This function calculates the factorial
# of a number using recursion
# It's used in probability calculations
def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n - 1)
```
