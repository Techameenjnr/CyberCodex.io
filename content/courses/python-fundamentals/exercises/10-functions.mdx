## Functions in Python

Functions are reusable blocks of code that perform specific tasks. They help you organize your code and avoid repetition!

### Defining a Function

Use the `def` keyword:

```python
def say_hello():
    print("Hello, World!")
```

### Calling a Function

To run a function, write its name followed by parentheses:

```python
say_hello()  # Outputs: Hello, World!
```

### Full Example

```python
# Define the function
def greet():
    print("Welcome!")
    print("Nice to see you!")

# Call the function
greet()
```

**Output:**
```
Welcome!
Nice to see you!
```

### Functions with Parameters

Functions can accept input values called **parameters**:

```python
def greet_person(name):
    print(f"Hello, {name}!")

greet_person("Alice")  # Hello, Alice!
greet_person("Bob")    # Hello, Bob!
```

### Functions with Return Values

Functions can send back a value using `return`:

```python
def add(a, b):
    return a + b

result = add(5, 3)
print(result)  # 8
```

### Why Use Functions?

1. **Reusability** - Write code once, use it many times
2. **Organization** - Break complex problems into smaller pieces
3. **Testing** - Easier to test and debug small functions
4. **Readability** - Makes code easier to understand

### Example: Multiple Uses

```python
def calculate_square(number):
    return number * number

print(calculate_square(4))   # 16
print(calculate_square(7))   # 49
print(calculate_square(10))  # 100
```

### Tip
Remember: Defining a function doesn't run it. You must call it!

```python
def my_function():  # This DEFINES the function
    print("Hi")

my_function()  # This RUNS the function
```
