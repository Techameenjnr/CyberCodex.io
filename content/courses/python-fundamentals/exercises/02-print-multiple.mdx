## Printing Multiple Lines

Now that you know how to print one message, let's learn how to print multiple messages!

### Multiple print() Statements

You can use the `print()` function as many times as you need. Each call to `print()` will display text on a new line.

```python
print("First line")
print("Second line")
print("Third line")
```

**Output:**
```
First line
Second line
Third line
```

### How it Works

- Python executes your code from top to bottom
- Each `print()` statement runs in order
- By default, `print()` adds a newline after each message
