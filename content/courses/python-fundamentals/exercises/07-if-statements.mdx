## Conditional Statements

Sometimes you want your code to do different things based on certain conditions. That's where `if` statements come in!

### Basic If Statement

The syntax for an `if` statement:

```python
if condition:
    # code to run if condition is True
    print("Condition was true!")
```

**Important:** The code inside the `if` block must be indented (4 spaces or 1 Tab).

### Comparison Operators

Use these to compare values:

| Operator | Meaning | Example |
|----------|---------|---------|
| `==` | Equal to | `x == 5` |
| `!=` | Not equal to | `x != 5` |
| `>` | Greater than | `x > 5` |
| `<` | Less than | `x < 5` |
| `>=` | Greater than or equal | `x >= 5` |
| `<=` | Less than or equal | `x <= 5` |

### Examples

```python
temperature = 75

if temperature > 70:
    print("It's warm outside!")
```

```python
password = "secret123"

if password == "secret123":
    print("Access granted!")
```

### The Colon and Indentation

Two critical parts of `if` statements:

1. **Colon (`:`)** - Must come after the condition
2. **Indentation** - Code inside the `if` must be indented

```python
# Correct ✓
if x > 10:
    print("x is big")

# Wrong ✗ (missing colon)
if x > 10
    print("x is big")

# Wrong ✗ (not indented)
if x > 10:
print("x is big")
```
