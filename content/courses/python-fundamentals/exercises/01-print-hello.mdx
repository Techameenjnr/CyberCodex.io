## Welcome to Python!

Python is one of the most popular programming languages in the world. It's used for web development, data science, artificial intelligence, and much more. Let's start with the basics!

### The print() Function

The `print()` function is used to display text (or other information) to the screen. This is one of the first things you'll learn in Python.

Here's the basic syntax:

```python
print("Your message here")
```

### How it Works

1. **Function name**: `print` - tells Python you want to display something
2. **Parentheses**: `()` - required for all functions
3. **String**: Text inside quotes (`"..."` or `'...'`) - what you want to display

### Example

```python
print("Welcome to CyberCodex!")
```

This will display: `Welcome to CyberCodex!`
