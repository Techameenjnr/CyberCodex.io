# Hello World

It's tradition in programming to start with a "Hello World" program. Let's write yours!

## The print() Function

The `print()` function is one of the most commonly used functions in Python. It displays text (or other data) to the screen.

### Basic Syntax

```python
print("Hello, World!")
```

When you run this code, Python will output:

```
Hello, World!
```

## Creating Your First Script

Instead of using the Python REPL, let's create a proper Python file:

1. Create a new file called `hello.py`
2. Add this code:

```python
print("Hello, World!")
```

3. Save the file
4. Run it from your terminal:

```bash
python3 hello.py
```

## Quotation Marks

In Python, you can use either single quotes `'` or double quotes `"` for strings:

```python
print('Hello with single quotes')
print("Hello with double quotes")
```

Both work the same way! Choose whichever you prefer (but be consistent).

## Multiple print() Statements

You can use multiple `print()` statements to display multiple lines:

```python
print("Line 1")
print("Line 2")
print("Line 3")
```

Output:
```
Line 1
Line 2
Line 3
```

## Fun Fact

The "Hello, World!" tradition started with Brian Kernighan's 1972 book "A Tutorial Introduction to the Language B". It was later popularized by "The C Programming Language" book in 1978.
