# ASCII Art Patterns

Let's have some fun with ASCII art! You can create patterns, shapes, and designs using just text characters.

## What is ASCII Art?

ASCII art is a graphic design technique that uses printable characters from the ASCII standard to create images. Before emojis and graphics, this was how people added visual flair to text!

## Creating Simple Patterns

You can use various characters to create patterns:

```python
print("*****")
print("*   *")
print("*   *")
print("*   *")
print("*****")
```

Output:
```
*****
*   *
*   *
*   *
*****
```

## Special Characters for Patterns

Here are some commonly used characters:

- `*` - Asterisk
- `#` - Hash
- `-` - Dash
- `|` - Pipe
- `/` and `\` - Slashes
- `_` - Underscore

## Example: Triangle

```python
print("    *")
print("   ***")
print("  *****")
print(" *******")
print("*********")
```

Output:
```
    *
   ***
  *****
 *******
*********
```

## Example: Diamond

```python
print("  *  ")
print(" *** ")
print("*****")
print(" *** ")
print("  *  ")
```

Output:
```
  *
 ***
*****
 ***
  *
```

## Pro Tip

When creating ASCII art, it helps to:

1. Plan your design on paper first
2. Count the spaces carefully
3. Use a monospace font in your editor
4. Build it line by line
